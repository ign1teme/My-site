首次使用，连接你的 GitHub 账号

后台已经就绪。完成一次授权配置后，就可以直接在这里管理网站内容。

  1. 在 GitHub 创建 OAuth App，将回调地址设为 。
  2. 在 Vercel 项目设置中填写 GITHUB_CLIENT_ID 和 GITHUB_CLIENT_SECRET。
  3. 确认仓库与生产分支配置，重新部署，然后回到这里登录。

详细步骤见项目中的 docs/admin-setup.md。密钥只填写在 Vercel 的环境变量中。
